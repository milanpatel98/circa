# MIMIC-IV Clinical Database Demo on FHIR, v2.1.0

The `fhir/` folder is the demo release exactly as published on PhysioNet:
https://physionet.org/content/mimic-iv-fhir-demo/2.1.0/

100 de-identified patients from Beth Israel Deaconess Medical Center. Dates are shifted into the future for privacy.
Licensed under the Open Database License v1.0 (`LICENSE.txt`). Please cite the dataset and PhysioNet when you use it.

`circa --data real ingest mimic/fhir` turns it into the charts Circa reads.
